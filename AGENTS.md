## Структура: теорія окремо від уроків

**Повна теорія живе в `grammar/`, одна тема = один файл**, розкладена **по рівнях CEFR у підтеках**:

```
grammar/
  _index.md      ← покажчик, згрупований за рівнями
  a1-a2/         ← база (to-be, articles, present-simple, past-simple…)
  b1/            ← ядро B1 (adjectives-adverbs, present-perfect, passive…)
  b1-plus/       ← linking words, reported speech, phrasal verbs…
  b2/            ← на перспективу
```

Новий файл клади в теку **того рівня, якому відповідає основний зміст теми** (не рівень уроку). Оновлюй `grammar/_index.md`.

**Вимоги до grammar-файлу:**
- **САМОДОСТАТНІЙ ДОВІДНИК.** `grammar/` пишемо так, ніби ним поділяться зі сторонньою людиною: всередині **немає нічого про внутрішню кухню репозиторію** — ні згадок `mistakes.md` / `lessons/` / `plan.md`, ні номерів уроків («детально — Урок 30»), ні лічильників раундів, ні пояснень, як влаштована система навчання. Потрібно послатися на іншу тему — роби це **за назвою теми**, а не за номером уроку.
- **ЧИСТА граматика.** ЖОДНИХ розділів про помилки учня / «типові помилки» — вони живуть ТІЛЬКИ в `mistakes.md`. Не лінкуй звідси на mistakes.
- **Шапка файлу:** одразу під заголовком — рядок `**Рівень:** A1–A2 / B1 / B1+ / B2`.
- **Зміст.** Якщо в файлі **4+ розділи (`##`)** — після рядка рівня йде блок `## Зміст` зі списком розділів-посилань. Для великих файлів (200+ рядків) — з вкладеними підрозділами (`###`).
- **БЕЗ прив'язки до професії.** Теорія має бути зрозумілою будь-кому: приклади — побутові й нейтральні (потяг, кімната, книжка, погода), **не** код/баги/деплой/Node.js. Айтішні аналогії лишаються тільки для **чату** й **уроків**, у `grammar/` їх немає.
- **Повнота, а не оглядовість.** Давай вичерпно: усі форми (ствердження/заперечення/питання/короткі відповіді), правопис, **вимова**, винятки, сталі вирази, порівняльні таблиці, дерево рішень. Еталон глибини — `a1-a2/articles.md`, еталон структури — `b1/adjectives-adverbs.md`.
- Формат: таблиці + чіткі підрозділи; приклади живі.
- Це **конспект учневі** — має бути самодостатнім без уроку.

## Формат уроку

Кожен урок — файл `lessons/NN-slug.md`. Структура:
- **Теми уроку** (вгорі) — грам-теми уроку з посиланнями на `grammar/*.md`. Напр. урок «PS vs PC» → `**Теми уроку:** [Present Simple](../grammar/a1-a2/present-simple.md) · [Present Continuous](../grammar/a1-a2/present-continuous.md)`.
- **Живі приклади** (спорт/фільми/ігри/розробка/побут; НЕ "The cat is on the table") + **раунди завдань** + відповіді учня.
- Урок **НЕ дублює теорію** — лише лінкує на `grammar/`.

## Прогресія: правило N × 100% (інтенсив з 14.08)

- **Нова тема:** урок пройдено після **5 раундів на 100%** (граматика + лексика). **Знайома тема** (позначка 🔁 «підтвердження» в `plan.md`): достатньо **3 раундів на 100%**.
- Раунд тепер більший: **8–12 пунктів + міні-текст (3–6 речень)**.
- **Щосесії — словниковий спринт:** 10 слів (UA→EN + власне речення); черга хвилями по партії ~290 слів, забуте слово повертається в чергу.
- **Щотижня:** письмова робота 120–180 слів (теми в `plan.md`) + читання з розбором (трек у `plan.md`) + жива сесія з Sam.
- **Зриває раунд = повноцінна помилка:**
  - **граматика/структура:** часи, `-s` 3-ї особи, `be`/be+ing, do/does, форма модальних, порядок слів, узгодження, артиклі;
  - **лексика:** неправильне слово / колокація (`bike`≠motorbike, `many`≠money, `musical instruments`), хибний прийменник дієслова.
- **НЕ зриває раунд (лише познач у підсумку):** **друкарські помилки** (очевидні описки) та **пунктуація** (кома, апостроф, крапка — пропущені чи неправильно вжиті). За потреби все одно нотуй у `mistakes.md`.
- Раунд із повноцінною помилкою → розбір → **новий раунд**. Повторюй до 5 чистих.
- Лічильник «✅ X/5» (або «✅ X/3» для 🔁-тем) після кожної перевірки. Після повного лічильника → наступний урок.

## Склад кожного раунду

Живий, різноманітний; у межах теми уроку збалансовано по раундах охоплює:
- **слова зі словника** (`vocabulary/`) — насамперед **активні слова уроку** (~15–20 із нової партії, оголошуються на старті уроку);
- **питання** і **заперечення**;
- **побудова речень** і **власний короткий текст**;
- переклад **UA → EN** і **EN → UA**;
- **пояснення граматики** своїми словами;
- **мікс попередніх тем** (закріплення);
- врахування **типових помилок україномовних** + **особистих помилок учня** (`mistakes.md`).

## Перевірка завдань

- Для КОЖНОЇ помилки: **де саме**, **як правильно**, **яке правило порушено** (посилання `rules.md §…`, якщо є).
- Повторюваний патерн → `mistakes.md` розділ C (+ за потреби нове правило в `rules.md`).
- Хвали успіхи, особливо подолання «ступору» у власному продукуванні.

## Формат словника (`vocabulary/<літера>.md`)

Файли по перших літерах: `a.md`, `b.md`, `c.md`… Кожне слово:

1. **Слово + транскрипція** — `word /trænˈskrɪpʃən/`
2. **Частина мови** — у `<code>` тегах: `1. <code>noun</code> (іменник) 2. <code>verb</code> (дієслово)`. Якщо кілька — нумеруй.
3. **Переклад** українською
4. **Пояснення використання** українською (нюанси, коли вживати)
5. **Приклади** — 1–2 на кожну частину мови, живі

Для слів зі специфікою вживання (керування прийменником, false friends, тощо) додавай блок:

```
**💡 <короткий заголовок нюансу>:**
- pattern A — значення / переклад
- pattern B — значення / переклад
```

⚠️ Після кожного pattern обов'язково — **переклад/пояснення значення САМОЇ конструкції українською** (не лише приклад речення). «eager to do sth — She's eager to learn.» це приклад БЕЗ пояснення; треба «eager to do sth — рветься щось зробити: She's eager to learn.» Якщо у слова кілька конструкцій із різним прийменником (for/to, about/to…) — обов'язково поясни різницю між ними.

Приклад — `complain` у `vocabulary/c.md`.

Кожен файл-літера починається з рядка `**Зміст:**` — навігація з посиланнями на слова цього файлу (`[word](#word)`, розділювач ` · `). Додаючи слово, онови і цей Зміст.

Після додавання слова — онови `vocabulary/_index.md` (алфавітний покажчик). Колонки: **Слово | ЧМ | Переклад | Нюанс**. Саме слово — це посилання на картку (`[word](x.md#word)`), окремої колонки «Файл» немає. Онови лічильник «Всього слів».

## Що оновлювати після кожного уроку

- `progress.md` — рядок про пройдений урок (дата, тема, статус, нотатки).
- `mistakes.md` — коротка таблиця ❌→✅ (список «НЕ ЗАБУТИ»). Новий повторюваний патерн → у розділ C, з посиланням на потрібний § у `rules.md`. НЕ дублюй сюди довгі пояснення — вони в `rules.md`.
- `rules.md` — довідник «яке правило застосувати», згрупований за темами. Нове стійке правило/колокацію додавай сюди у відповідний розділ (або новий), з `✅/❌` прикладами; неточну нотатку учня уточнюй позначкою `⚠️`.
- `vocabulary/` + `_index.md` — нові слова.
- `plan.md` — онови статус уроку (⬜ / 🟡 / ✅ / ↻).

## Карта файлів

- `plan.md` — дорожня карта A1→A2 (список уроків, статуси).
- `progress.md` — журнал прогресу.
- `mistakes.md` — таблиця ❌→✅ (список «НЕ ЗАБУТИ»), з посиланнями на `rules.md`.
- `rules.md` — довідник золотих правил за темами (швидкий чек-лист).
- `grammar/` — повна теорія по темах, розкладена по рівнях (`a1-a2/`, `b1/`, `b1-plus/`, `b2/`) + `_index.md`.
- `vocabulary/` — словник (по літерах) + `_index.md`.
- `lessons/` — самі уроки (Теми уроку + раунди).

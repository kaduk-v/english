# 🇬🇧 English — A1 → A2

Персональна система вивчення англійської. Мета — **впевнений A1–A2 CEFR**: щоб вільно складати речення й говорити, а не лише читати/перекладати.

## 🧭 Навігація

- 📚 **[Уроки](lessons/)** — усі уроки
- 📖 **[Словник](vocabulary/_index.md)** — покажчик усіх слів
- 🗺️ [План](plan.md) · 🔑 [Правила](rules.md) · 📌 [Помилки](mistakes.md)

## Як це працює

- Вчимося **уроками** за планом (`plan.md`). Кожен урок = жива теорія + приклади з життя + завдання (переклади в обидва боки, власні речення, пояснення граматики).
- Ритм: **2 уроки → 1 закріплення**.
- Усе, що вивчаємо, осідає у **словнику** (`vocabulary/`) і в **журналі помилок** (`mistakes.md`), щоб повертатися й повторювати.

## Структура

```
english/
├── plan.md            ← дорожня карта A1→A2 (усі уроки)
├── progress.md        ← що пройдено, коли
├── mistakes.md        ← типові пастки + твої зафіксовані помилки
├── vocabulary/        ← словник по літерах (a.md, b.md, c.md…)
│   └── _index.md      ← алфавітний покажчик усіх слів
├── lessons/           ← самі уроки
└── AGENTS.md          ← інструкції для Claude (формати, конвенції)
```

## Як користуватися

- **Почати/продовжити урок:** «Погнали урок 1» / «Наступний урок».
- **Додати слова:** кидай список — вони підуть у словник у правильному форматі.
- **Повторити помилки:** «Покажи мої часті помилки» / «Зроби вправу на мої помилки».
- **Перевірити прогрес:** дивись `progress.md`.

> Порада: для англійських сесій запускай Claude Code саме з теки `english/` — тоді він одразу підхопить `AGENTS.md` з усіма форматами.

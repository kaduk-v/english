# 🇬🇧 English — шлях до B1+

Персональна система вивчення англійської. Мета — **впевнений B1+ CEFR** (вимога роботи мрії): великий активний словник, вільне читання, впевнене письмо — а не лише читати/перекладати. A1-ядро закрито в липні 2026.

## 🧭 Навігація

- 📚 **[Уроки](lessons/)** — усі уроки
- 📗 **[Граматика](grammar/_index.md)** — повна теорія по темах, розкладена по рівнях (A1–A2 / B1 / B1+ / B2)
- 📖 **[Словник](vocabulary/_index.md)** — покажчик усіх слів
- 🗺️ [План](plan.md) · 🔑 [Правила](rules.md) · 📌 [Помилки](mistakes.md)

## Як це працює

- Вчимося **уроками** за планом (`plan.md`): 7 модулів до B1+ (L11–L40). Кожен урок = теорія в `grammar/` + великі раунди завдань (8–12 пунктів + міні-текст).
- **Прогресія:** нова тема — 5 чистих раундів × 100%; знайома (🔁) — 3 × 100%.
- **Щосесії:** словниковий спринт (10 слів). **Щотижня:** письмова робота 120–180 слів + читання з розбором + жива сесія з Sam (рольовий чат).
- Усе, що вивчаємо, осідає у **словнику** (`vocabulary/`) і в **журналі помилок** (`mistakes.md`), щоб повертатися й повторювати.

## Структура

```
english/
├── plan.md            ← дорожня карта до B1+ (7 модулів, усі уроки)
├── progress.md        ← що пройдено, коли
├── mistakes.md        ← типові пастки + твої зафіксовані помилки
├── rules.md           ← швидкий довідник золотих правил
├── grammar/           ← теорія по темах, по рівнях: a1-a2/ b1/ b1-plus/ b2/ (+ _index.md)
├── vocabulary/        ← словник по літерах (a.md, b.md, c.md…)
│   └── _index.md      ← алфавітний покажчик усіх слів
├── lessons/           ← самі уроки
└── AGENTS.md          ← інструкції для Claude (формати, конвенції)
```

## Як користуватися

- **Почати/продовжити урок:** «Погнали урок 1» / «Наступний урок».
- **Додати слова:** кидай список — вони підуть у словник у правильному форматі.
- **Повторити помилки:** «Покажи мої часті помилки» / «Зроби вправу на мої помилки».
- **Перевірити прогрес:** дивись `progress.md`.

> Порада: для англійських сесій запускай Claude Code саме з теки `english/` — тоді він одразу підхопить `AGENTS.md` з усіма форматами.

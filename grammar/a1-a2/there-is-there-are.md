## 1. Навіщо ця конструкція

`There is / There are` повідомляє, що щось **є, існує, знаходиться десь** — і вводить це в розмову як **нову** інформацію.

| Українською | Англійською |
|---|---|
| У кімнаті **є** вікно. | **There is** a window in the room. |
| На столі дві чашки. | **There are** two cups on the table. |
| Учора **був** дощ. | **There was** rain yesterday. |
| Біля дому **буде** парк. | **There will be** a park near the house. |
| У холодильнику **немає** молока. | **There is no** milk in the fridge. |

**Чому не можна просто перекласти слово в слово.** В українському реченні часто немає ні підмета, ні дієслова («На столі дві чашки») або дієслово стоїть першим («Є одна проблема»). Англійське речення так не може: **підмет мусить стояти перед дієсловом.** Слово `there` займає місце підмета — це «формальний підмет», заглушка. Справжня інформація («що саме є») іде після дієслова.

> `there` у цій конструкції **не перекладається** і нічого не означає. Це не «там». «Там» — інше `there`, див. [розділ 8](#_8-два-різні-there-here-is).

## 2. Усі форми

### Теперішній час

| | Однина / незлічуване | Множина |
|---|---|---|
| ствердження | **There is** a café near my house. | **There are** three cafés near my house. |
| заперечення | **There isn't** a café near here. | **There aren't** any cafés near here. |
| питання | **Is there** a café near here? | **Are there** any cafés near here? |
| коротка відповідь | Yes, there **is**. / No, there **isn't**. | Yes, there **are**. / No, there **aren't**. |

### Минулий час

| | Однина / незлічуване | Множина |
|---|---|---|
| ствердження | **There was** a fair in the town. | **There were** a lot of people at the fair. |
| заперечення | **There wasn't** a fair this year. | **There weren't** any tickets left. |
| питання | **Was there** a fair last Sunday? | **Were there** many people? |
| коротка відповідь | Yes, there **was**. / No, there **wasn't**. | Yes, there **were**. / No, there **weren't**. |

### Майбутній час

`will` не змінюється — однина й множина однакові, `be` стоїть завжди:

| | Приклад |
|---|---|
| ствердження | **There will be** a concert in the park tomorrow. · **There will be** two concerts. |
| заперечення | **There won't be** any rain at the weekend. |
| питання | **Will there be** a lot of people? — Yes, there **will**. / No, there **won't**. |

> ❌ There will a concert. — після `will` обов'язково `be`.

### З модальними дієсловами

Те саме правило: модальне + **be**: There **can be** problems with the connection. · There **must be** a mistake. · There **should be** a sign on the door.

## 3. Is чи are: узгодження

Дієслово дивиться на іменник **після** нього:

| Що після дієслова | Форма | Приклад |
|---|---|---|
| a / an + однина | is / was | There **is a** problem. |
| незлічуване | is / was | There **is** some milk. · There **was** a lot of noise. |
| множина | are / were | There **are** two problems. |
| a lot of / many / some + множина | are / were | There **are a lot of** tourists. |
| a lot of / much + незлічуване | is / was | There **is a lot of** traffic. |
| число | are / were | There **were** fifty people. |

**Перелік — за першим іменником:**
- There **is** a table and two chairs. *(перший — однина)*
- There **are** two chairs and a table. *(перший — множина)*

> У розмовній мові часто чути **there's** + множина (*There's two cafés*). У письмі й на іспиті — тільки **there are**.

## 4. Що стоїть після there is: a, some, any, no

`There is` вводить **нове** — тому після нього майже завжди **a / an**, **some**, **any**, **no** або число, а не `the`.

| | Ствердження | Заперечення | Питання |
|---|---|---|---|
| однина | There is **a** key. | There isn't **a** key. / There is **no** key. | Is there **a** key? |
| множина | There are **some** keys. | There aren't **any** keys. / There are **no** keys. | Are there **any** keys? |
| незлічуване | There is **some** water. | There isn't **any** water. / There is **no** water. | Is there **any** water? |

- **a / an** — один предмет, що з'являється вперше: There's **an** old fortress on the hill. *(`an` — перед голосним звуком)*
- **the** після there is майже не трапляється: `the` означає «вже відоме», а there is — «ось нове». ❌ There was the fair in our town. → ✅ There was **a** fair in our town. Коли ж мова про вже відоме — переходимо на інший підмет: ✅ There was **a fair** in our town. **The fair** was very big.
- **no** = **not a / not any**: There is **no** time. = There isn't **any** time. Після `no` артикля немає.
- **nothing / nobody / nowhere**: There's **nothing** in the box. · There was **nobody** at home.

## 5. Порядок слів: обставина часу чи місця на початку

Це найважливіший розділ для україномовних. В українській звичний порядок — **спочатку де / коли, потім «є / було», потім що**:

> **Учора** в кафе **було** багато людей. · **Біля** прилавків **було** багато людей. · **У** моїй грі **є** старий будинок.

Якщо перекласти слово в слово, вийде речення без підмета:

> ❌ Yesterday were many people in the café. · ❌ Near the counters were many people. · ❌ In my game is an old house.

Обставина часу (`yesterday`, `last month`) чи місця (`near the counters`, `in my game`) **не може бути підметом**. Підмета немає — отже, потрібне `there`.

### Два правильні варіанти

| | Схема | Приклад |
|---|---|---|
| **А. Нейтральний** (найчастіший) | There + be + **що** + де / коли | **There were** a lot of people in the café yesterday. |
| **Б. Обставина на початку** | Де / коли + **there** + be + що | **Yesterday there were** a lot of people in the café. |

Обидва правильні. У варіанті Б `there` стоїть **одразу після** обставини — перед дієсловом.

### Більше прикладів

| Українською | ✅ Варіант А | ✅ Варіант Б |
|---|---|---|
| Учора в офісі була одна проблема. | There was a problem at the office yesterday. | Yesterday there was a problem at the office. |
| Біля прилавків було багато людей. | There were many people near the counters. | Near the counters there were many people. |
| У моїй кімнаті є старий стіл. | There is an old desk in my room. | In my room there is an old desk. |
| Минулого місяця були проблеми з терміналом. | There were problems with the terminal last month. | Last month there were problems with the terminal. |
| Завтра буде концерт. | There will be a concert tomorrow. | Tomorrow there will be a concert. |

> **Як перевірити себе:** знайди в українському реченні «є / був / була / було / були / буде». Якщо **перед ним** стоїть час або місце, а **після** — те, що існує, англійською потрібне `there`.

### Коли there НЕ потрібне

Якщо у реченні вже є справжній підмет — той, **про кого / про що** говоримо, — `there` не ставимо, а дієслово `be` пов'язує підмет з місцем:

| Про що речення? | Конструкція | Приклад |
|---|---|---|
| **що є** в кімнаті (нове) | there is | **There is** a cat in the kitchen. |
| **де** відомий предмет | підмет + be + місце | **The cat is** in the kitchen. *(той самий, наш кіт)* |
| **де** відома людина | підмет + be + місце | **My keys are** on the table. |

Українською обидва — «Кіт на кухні», але англійською різниця: нова річ → `there is a…`; відома річ → `the … is…`.

## 6. There is чи it is

| `There is` | `It is` |
|---|---|
| вводить **нове**: «існує, є» | **описує** вже відоме або погоду, час, відстань |
| **There's** a new café near the station. | **It's** small but cosy. |
| **There was** a storm last night. | **It was** very loud. |
| **There's** a problem with the door. | **It's** broken. |

Типова пара: **There is** + що → **It is** + яке.
- **There's** a fortress on the hill. **It's** very old.
- **There was** a concert yesterday. **It was** amazing.

---

## 7. There is чи have: у когось є

Українське «у когось є» звучить як «є» — але англійською це **have**, а не there is.

| Хто / що «має» | Конструкція | Приклад |
|---|---|---|
| **людина, тварина, організація** | have / has | **I have** a car. · **The neighbours have** some boards. · **The café has** a terrace. |
| **місце, простір, ємність** | there is / are | **There is** a terrace at the café. · **There are** boards in the barn. |

- «У мене є ідея» → ✅ **I have** an idea. ❌ There is an idea in me.
- «У сусідів є дошки» → ✅ **The neighbours have** boards. ❌ Boards are in the neighbours.
- «У кімнаті є шафа» → ✅ **There is** a wardrobe in the room. *(кімната — місце)*

## 8. Два різні there; here is

| | Значення | Позиція | Приклад |
|---|---|---|---|
| **there** у *there is* | формальний підмет, не перекладається | на початку, перед be | **There** is a bench in the park. |
| **there** = «там» | місце | зазвичай у кінці | I met an old friend **there**. |
| обидва разом | | | **There** is a bench **there**. — Там є лавка. |

**Here is / Here are** — «ось» (коли показуєш або даєш): **Here is** your coffee. · **Here are** the keys. Це не те саме, що there is: here is не повідомляє про існування, а вказує.

> Не плутай на письмі: **there** (там / формальне) · **their** (їхній) · **they're** (= they are). Вимова однакова.

## 9. Вимова і скорочення

| Повна форма | Скорочення | Вимова |
|---|---|---|
| there is | **there's** | /ðeəz/ |
| there are | *(у письмі не скорочуємо)* | /ðeərɑː/, у швидкій мові /ðərə/ |
| there is not | **there isn't** / there's not | /ðeər ˈɪznt/ |
| there are not | **there aren't** | /ðeər ɑːnt/ |
| there was not | **there wasn't** | /ðeə ˈwɒznt/ |
| there will | **there'll** | /ðeəl/ |
| there will not | **there won't** | /ðeə wəʊnt/ |

- Звук **/ð/** — дзвінкий, кінчик язика між зубами (як у *the, this*), не «з» і не «д».
- У швидкому мовленні `there` в цій конструкції ненаголошене: *There's a* … звучить як /ðəzə/.
- У питаннях **is / are / was / were** виходять наперед і наголошені: **Is** there…? **Were** there…?

## 10. Сталі вирази

| Вираз | Значення | Приклад |
|---|---|---|
| **There's no time.** | Немає часу. | Hurry up, **there's no time**! |
| **There's no need to** + дієслово | Не треба, немає потреби | **There's no need to** shout. |
| **There's no point (in)** + -ing | Немає сенсу | **There's no point in** waiting. |
| **There's nothing to** + дієслово | Нема чого (робити) | **There's nothing to** eat. |
| **There's something wrong with** … | Щось не так з … | **There's something wrong with** the car. |
| **Is there anything else?** | Ще щось? | — **Is there anything else?** — No, thanks. |
| **There you go / There you are.** | Ось, тримай (подаючи) | **There you go** — one coffee. |
| **There's a lot of** … | Багато (незлічуваного) | **There's a lot of** snow this year. |

## 11. Дерево рішень

1. Речення повідомляє, що щось **існує / є / було / буде** десь чи колись?
   - **Ні** → звичайне речення з підметом: *The cat is in the kitchen.*
   - **Так** → іди далі.
2. «Є» належить **людині / організації** («у мене є», «у сусідів є»)?
   - **Так** → **have / has**: *I have a car.*
   - **Ні** → **there + be**.
3. Що після дієслова — однина / незлічуване чи множина?
   - однина, незлічуване → **is / was / will be**
   - множина, число → **are / were / will be**
4. Однина злічувана → **a / an**; множина в запереченні / питанні → **any**; «немає» → **no**.
5. Хочеш почати з часу чи місця? → **обставина + there + be + …** (`there` не губиться).

## 1. Головна ідея

Коли ми хочемо зробити з **дії** («вчити», «бігати», «чекати») **предмет розмови** — підмет чи додаток речення («вивчення», «біг», «очікування»), ми перетворюємо дієслово на іменник за допомогою закінчення **-ing**. Така форма називається **герундій** (gerund).

| Дія (дієслово) | Дія як «предмет» (герундій) | Приклад |
|---|---|---|
| learn — вчити | **learning** — вивчення, навчання | **Learning** a language takes time. |
| run — бігати | **running** — біг | **Running** is good for your heart. |
| wait — чекати | **waiting** — очікування | I hate **waiting**. |
| cook — готувати | **cooking** — готування, кулінарія | She is good at **cooking**. |

Українською ми для цього маємо окремі іменники («вивчення», «читання», «біг») або інфінітив («Вчити мову важко»). Англійською — одне просте правило: **дієслово + -ing**, і воно поводиться як іменник.

> Герундій — це **іменник за роллю, але дієслово за природою**: він може мати свій об'єкт і прислівник. *Learning **a new language quickly** is hard.* — тут `a new language` — об'єкт, `quickly` — прислівник.

## 2. Як утворити -ing

Правопис той самий, що в Present Continuous:

| Правило | Приклад |
|---|---|
| більшість дієслів — просто + **-ing** | read → read**ing** · play → play**ing** |
| німа **-e** зникає | make → mak**ing** · write → writ**ing** |
| **-ee** лишається | see → se**eing** · agree → agre**eing** |
| **-ie** → **-y** | lie → l**ying** · die → d**ying** |
| коротке слово «приголосна + наголошена голосна + приголосна» — подвоєння | run → ru**nn**ing · swim → swi**mm**ing · stop → sto**pp**ing |
| **-w, -x, -y** не подвоюються | fix → fix**ing** · play → play**ing** |

Вимова закінчення: /ɪŋ/ — без «г» у кінці (не «рідінг», а /ˈriːdɪŋ/).

## 3. -ing як підмет

Коли **дія** стоїть на місці підмета (про неї щось кажуть), вона завжди має форму **-ing**. Базова форма дієслова підметом бути не може.

| ❌ | ✅ | Переклад |
|---|---|---|
| Learn English is hard. | **Learning** English is hard. | Вчити англійську важко. |
| Run the café is not easy. | **Running** a café is not easy. | Керувати кав'ярнею нелегко. |
| Swim in the sea is fun. | **Swimming** in the sea is fun. | Плавати в морі весело. |

**Дієслово після такого підмета — в однині:** герундій — це одна дія, навіть якщо в ній багато слів.
- **Reading** books **is** my hobby. *(не «are» — підмет `reading`, а не `books`)*
- **Learning** new words **takes** time.

**Чому так.** Українською «Вчити англійську — важко» спокійно починається з інфінітива. Англійською інфінітив на початку (`To learn English is hard`) граматично можливий, але звучить книжно й урочисто. У звичайній мові підмет-дія — це **-ing**.

## 4. -ing після прийменника

Після **будь-якого** прийменника (about, of, for, in, at, before, after, without, by…) дієслово стоїть у формі **-ing**:

| Прийменник | Приклад | Переклад |
|---|---|---|
| before | Wash your hands **before eating**. | Мий руки перед їжею. |
| after | **After finishing** work, I go for a walk. | Закінчивши роботу, я йду гуляти. |
| without | She left **without saying** goodbye. | Вона пішла, не попрощавшись. |
| by | You learn **by doing**. | Вчишся, роблячи. |
| about | I'm thinking **about moving** to the sea. | Я думаю про переїзд до моря. |
| of | He's tired **of waiting**. | Йому набридло чекати. |
| for | Thanks **for helping** me. | Дякую, що допоміг. |
| in | She's interested **in learning** Spanish. | Вона цікавиться вивченням іспанської. |
| at | He's good **at drawing**. | Він добре малює. |

> ❌ Thanks for help me. · ❌ I'm thinking about to move. · ❌ before start.
> ✅ Thanks for **helping** me. · ✅ I'm thinking about **moving**. · ✅ before **starting**.

**Пастка з `to`.** У кількох виразах `to` — це **прийменник**, а не частка інфінітива, тому після нього теж **-ing**:
- look forward **to seeing** you — чекаю на зустріч
- be used **to getting** up early — звик рано вставати
- object **to working** late — заперечувати проти роботи допізна

Тест: якщо після `to` можна поставити іменник (*look forward to **the weekend***), то це прийменник → **-ing**.

## 5. -ing після певних дієслів

Деякі дієслова вимагають після себе **-ing** (не `to`). Їх треба запам'ятати разом:

| Дієслово | Значення | Приклад |
|---|---|---|
| **enjoy** | любити, отримувати задоволення | I **enjoy cooking** at the weekend. |
| **finish** | закінчити | Have you **finished reading** the book? |
| **stop** | перестати | **Stop talking**, please. |
| **avoid** | уникати | I **avoid driving** in the city. |
| **mind** | заперечувати (у питаннях) | Do you **mind opening** the window? |
| **keep** | продовжувати (знову і знову) | He **keeps forgetting** his keys. |
| **suggest** | пропонувати | She **suggested going** to the cinema. |
| **recommend** | радити | I **recommend trying** the soup. |
| **imagine** | уявляти | **Imagine living** by the sea. |
| **miss** | сумувати за | I **miss playing** football. |
| **practise** | тренуватися | **Practise speaking** every day. |
| **spend** (time / money) | витрачати час на | I **spent** an hour **looking** for my keys. |

> ❌ I enjoy to cook. · ❌ She suggested to go. · ❌ I recommend to try.

## 6. -ing чи to + дієслово

### Тільки to + дієслово

Ці дієслова — про намір, рішення, бажання (часто про майбутнє):

| Дієслово | Приклад |
|---|---|
| want, would like | I **want to learn** Spanish. |
| plan, decide | We **decided to stay** at home. |
| hope, expect | I **hope to see** you soon. |
| need | You **need to rest**. |
| learn | She's **learning to drive**. |
| agree, promise, refuse | He **promised to call**. |
| can't afford | We **can't afford to wait**. |

### Обидва варіанти, той самий зміст

**start, begin, like, love, hate, prefer, continue** — можна і так, і так:
- It **started raining**. = It **started to rain**.
- I **like swimming**. = I **like to swim**. *(-ing — радше «люблю як заняття»)*

> ⚠️ Після `would like / would love / would prefer` — **тільки to**: I**'d like to** go. ❌ I'd like going.

### Обидва варіанти, різний зміст

| | + -ing | + to + дієслово |
|---|---|---|
| **stop** | перестати робити: I **stopped smoking**. — Я кинув палити. | зупинитись, щоб зробити: I **stopped to smoke**. — Я зупинився, щоб покурити. |
| **remember** | пам'ятати, що зробив (минуле): I **remember locking** the door. | не забути зробити (майбутнє): **Remember to lock** the door. |
| **forget** | забути, що зробив: I'll never **forget meeting** her. | забути зробити: Don't **forget to call** me. |
| **try** | спробувати як експеримент: **Try adding** salt. | намагатися (важко): I **tried to open** the jar. |

## 7. Заперечення: not + -ing

`not` стоїть **перед** герундієм:
- **Not knowing** the rules is not an excuse. — Не знати правил — не виправдання.
- I'm sorry for **not calling** you. — Вибач, що не подзвонив.
- He left **without** paying. *(without уже заперечує — not не потрібен)*

---

## 8. Три різні -ing: герундій, Continuous, прикметник

Форма однакова — роль різна. Визначай за місцем у реченні:

| Роль | Як упізнати | Приклад |
|---|---|---|
| **Герундій** (іменник) | стоїть як підмет, після прийменника або після enjoy / stop / finish… | **Swimming** is fun. · I'm good at **swimming**. |
| **Present / Past Continuous** (дієслово) | перед ним **am / is / are / was / were** — дія в процесі | She **is swimming** now. |
| **Прикметник на -ing** | описує іменник, відповідає на «який?» | a **boring** film · an **exciting** game |

- **Reading** is my hobby. — герундій (підмет).
- I **am reading** a book. — Continuous (процес зараз).
- This book is **interesting**. — прикметник.

## 9. Сталі вирази з -ing

| Вираз | Значення | Приклад |
|---|---|---|
| **be good / bad at** + -ing | добре / погано вміти | She's **good at explaining** things. |
| **be interested in** + -ing | цікавитися | I'm **interested in learning** to cook. |
| **be tired of** + -ing | набридло | I'm **tired of waiting**. |
| **look forward to** + -ing | з нетерпінням чекати | I **look forward to hearing** from you. |
| **How about / What about** + -ing? | А як щодо…? (пропозиція) | **How about going** to the park? |
| **It's no use** + -ing | марно | **It's no use crying**. |
| **There's no point (in)** + -ing | немає сенсу | **There's no point in arguing**. |
| **It's worth** + -ing | варто | The museum **is worth visiting**. |
| **be busy** + -ing | бути зайнятим чимось | She's **busy cooking**. |
| **spend time** + -ing | проводити час за | We **spent the evening talking**. |

## 10. Дерево рішень

Після дієслова чи на місці підмета треба поставити ще одне дієслово. Яку форму?

1. Дія — **підмет** речення (про неї щось кажуть)? → **-ing**: *Learning is fun.*
2. Перед дієсловом **прийменник** (about, of, for, at, in, before, after, without, by)? → **-ing**: *before leaving*.
   - `to` — прийменник (look forward to, be used to, object to)? → **-ing**.
3. Перед ним дієслово з групи **enjoy / finish / stop / avoid / mind / keep / suggest / recommend / miss / imagine**? → **-ing**.
4. Перед ним **want / plan / decide / hope / need / learn / promise / would like / can't afford**? → **to + дієслово**.
5. **start / begin / like / love / hate**? → обидва.
6. **stop / remember / forget / try**? → обидва, але зміст різний — див. [розділ 6](#_6-ing-чи-to-дієслово).

## 11. Перевір себе

Обери правильну форму.

1. (Learn / Learning) a new language takes time.
2. I'm tired of (wait / waiting).
3. She decided (to buy / buying) a bike.
4. Thanks for (help / helping) me.
5. I enjoy (to walk / walking) in the rain.
6. Would you like (to come / coming) with us?
7. He stopped (to smoke / smoking) last year. *(кинув)*
8. I look forward to (see / seeing) you.

<details>
<summary>Відповіді</summary>

1. **Learning** — дія як підмет.
2. **waiting** — після прийменника `of`.
3. **to buy** — decide + to.
4. **helping** — після прийменника `for`.
5. **walking** — enjoy + -ing.
6. **to come** — would like + to.
7. **smoking** — stop + -ing = перестати.
8. **seeing** — `to` тут прийменник (look forward to + іменник / -ing).

</details>

# Наказовий спосіб (Imperatives)

Команда / інструкція / порада — **базове дієслово без підмета**.

- ствердження: **Open** the door. · **Press** Start. · **Turn** left.
- заперечення: **Don't** + base → **Don't** touch that. · **Don't** be late.
- ввічливо: **Please** sit down. / Sit down, **please**.
- «давай(мо)» (пропозиція): **Let's** + base → **Let's** play.

**Де вживається:** рецепти, інструкції, вказівки, поради, дорожні/ігрові знаки (Push / Pull / Do not enter / Press Start).

**Типові помилки:**
- ❌ You open the door _(як команда)_ → ✅ **Open** the door.
- ❌ No touch → ✅ **Don't** touch.

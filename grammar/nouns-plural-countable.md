# Іменники: множина та countable / uncountable

# 1. Множина (Plural)

## Правильна множина

| Правило | Приклад |
|---|---|
| зазвичай `+s` | book → book**s**, car → car**s** |
| після -s, -sh, -ch, -x, -z → `+es` | bus → bus**es**, brush → brush**es**, watch → watch**es**, box → box**es** |
| приголосна + y → `ies` | city → cit**ies**, baby → bab**ies** |
| голосна + y → `+s` | boy → boy**s**, key → key**s** |
| -f / -fe → `ves` | leaf → lea**ves**, knife → kni**ves**, wife → wi**ves**, shelf → shel**ves** |
| винятки з -f | roof → roof**s**, chief → chief**s**, belief → belief**s** |
| -o → `+es` (живе/їстівне) | potato → potato**es**, tomato → tomato**es**, hero → hero**es** |
| -o → `+s` (запозичення, скорочення) | photo**s**, piano**s**, video**s**, kilo**s** |

## 🔊 Вимова -s (як у дієслів)

| Звук | Коли | Приклад |
|---|---|---|
| /s/ | після глухих p, t, k, f | books, cats, maps |
| /z/ | після дзвінких і голосних | dogs, cars, boys |
| /ɪz/ | після s, sh, ch, x, ge | buses, watches, boxes |

## Неправильна множина

| Однина | Множина |
|---|---|
| man | **men** |
| woman | **women** *(вимова: /ˈwɪmɪn/!)* |
| child | **children** |
| person | **people** |
| foot | **feet** |
| tooth | **teeth** |
| goose | **geese** |
| mouse | **mice** |
| ox | **oxen** |

## Однакова форма (однина = множина)
**sheep, fish, deer, series, species, aircraft, means**
- one sheep → two **sheep** · one series → two **series**

## Латинські / грецькі
| Однина | Множина |
|---|---|
| analysis | analys**es** |
| basis | bas**es** |
| crisis | cris**es** |
| criterion | criter**ia** |
| phenomenon | phenomen**a** |
| datum | dat**a** |
| cactus | cact**i** |

## Завжди множина (парні / складені)
**trousers, jeans, shorts, glasses, sunglasses, scissors, clothes, headphones**
- My jeans **are** new. *(не «is»)*
- Щоб порахувати → **a pair of**: two **pairs of** scissors.

## Виглядають як множина, але однина
**news, maths, physics, economics, politics, athletics**
- The news **is** good. *(не «are»)*

# 2. Countable vs Uncountable

| | Countable (злічувані) | Uncountable (незлічувані) |
|---|---|---|
| **множина** | так: a car → cars | ні: ~~waters~~, ~~informations~~ |
| **артикль a/an** | так: **a** car | ні: ~~a music~~ |
| **числа** | two cars | ~~two waters~~ |
| **дієслово** | The cars **are** … | Water **is** … |
| **кількість** | many / a few / How many | much / a little / How much |

## Типові uncountable

| Категорія | Приклади |
|---|---|
| рідини, речовини | water, milk, coffee, tea, air, oil |
| матеріали | wood, metal, paper, glass, plastic |
| абстрактні | love, time, stress, wisdom, success, luck, freedom, help |
| збірні | money, furniture, luggage, equipment, traffic, rubbish |
| «інформаційні» | information, advice, news, knowledge, research, homework, work |
| їжа масою | bread, cheese, rice, meat, butter, sugar |
| мови, предмети | English, maths, music |
| погода | weather, rain, snow, sunshine |

> ⚠️ Найпідступніші (в укр. злічувані, в англ. — НІ):
> **information, advice, news, furniture, luggage, money, work, research, knowledge, progress**
> - ✅ some **advice** *(не «an advice», не «advices»)*
> - ✅ **money is** … *(не «monies are»)*

## Як «порахувати» uncountable — одиниці виміру

| Вираз | Приклад |
|---|---|
| **a piece of** | a piece of advice / information / news / furniture |
| **a glass / cup / bottle of** | a glass of water, a cup of coffee |
| **a slice / loaf of** | a slice of bread, a loaf of bread |
| **a bar of** | a bar of chocolate |
| **a kilo of** | a kilo of sugar |
| **an item of** | an item of clothing |

# 3. Слова, що бувають і C, і U (зі зміною значення)

| Слово | Uncountable | Countable |
|---|---|---|
| **hair** | волосся (все) — Her hair **is** long. | волосина — There's **a hair** in my soup. |
| **paper** | папір — I need **paper**. | газета / стаття — I read **a paper**. |
| **glass** | скло — made of **glass** | склянка — **a glass** of water |
| **coffee** | кава (речовина) — I like **coffee**. | чашка кави — Two **coffees**, please. |
| **time** | час — I have no **time**. | раз — three **times** |
| **room** | місце, простір — Is there **room**? | кімната — **a room** |
| **chicken** | курятина — I eat **chicken**. | курка — **a chicken** |
| **light** | світло — There's **light**. | лампа — turn on **the lights** |
| **experience** | досвід — I have **experience**. | випадок — **an experience** |
| **success** | успіх — achieve **success**. | успішна подія — It was **a success**. |

# 4. Кількість: коротко

| | Countable | Uncountable | Обидва |
|---|---|---|---|
| багато | **many** games | **much** time | **a lot of / lots of** |
| трохи | **a few** friends | **a little** water | **some** |
| мало (недостатньо) | **few** friends | **little** water | — |
| питання | **How many** games? | **How much** time? | — |
| заперечення / питання | **any** | **any** | — |

- `much` у ствердженні звучить формально → у побуті **a lot of**: ✅ I have **a lot of** work.
- `a few` = «кілька» *(позитивно)* · `few` = «мало» *(негативно)*

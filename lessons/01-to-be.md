# Урок 1 — Дієслово to be (am / is / are)

**Теми уроку:** [to be](../grammar/a1-a2/to-be.md)
**Статус:** ✅ пройдено *(перевірено діагностикою — Урок 0; be-radar відпрацьовано)* · **матеріал для повторення**

> 📗 Теорія-конспект: [grammar/a1-a2/to-be.md](../grammar/a1-a2/to-be.md)

## Живі приклади
- I**'m** a backend developer, and this **is** my first mobile app. — Я бекенд-розробник, і це мій перший мобільний застосунок.
- **Is** she online? — No, she **isn't**. — Вона в мережі? — Ні.
- **It's** cold today, so the match **is** cancelled. — Сьогодні холодно, тому матч скасовано.
- **There are** two bugs in the code, but **there isn't** any time to fix them. — У коді два баги, але немає часу їх виправити.
- I**'m** 30, I**'m** hungry, and you**'re** right. — Мені 30, я голодний, і ти правий.

## 🔁 Раунд для повторення
1. **EN → UA:** There is a problem with the server, but it isn't serious.
2. **UA → EN:** Я програміст. Мені 30 років.
3. **UA → EN:** Сьогодні холодно. *(порожній підмет!)*
4. **UA → EN:** Вони не втомлені? — Ні, вони втомлені. *(питання + коротка відповідь)*
5. **Речення:** 2 речення про себе з `be` — одне ствердне, одне заперечне (+ словникове слово).
6. **Поясни:** чому «He tired» і «Is cold» — неправильно?

## safety
**safety** /ˈseɪfti/ — <code>noun</code> (іменник) — безпека

**Пояснення:** стан, коли нічого не загрожує; захищеність від небезпеки. Іменник від **safe** (безпечний).

**💡 Для розробника:** **type safety** — типобезпечність (головний аргумент за TypeScript); **safety check** — перевірка безпеки.

**Приклади:**
- TypeScript adds **type safety** to JavaScript. — TypeScript додає типобезпечність у JavaScript.
- Wear a helmet for your own **safety**. — Носи шолом заради власної безпеки.

🔗 **Пов'язане:** safe — безпечний (прикметник).

## scratch
**scratch** /skrætʃ/ — 1. <code>verb</code> (дієслово) 2. <code>noun</code> (іменник) — 1. дряпати; чухати 2. подряпина

**Приклади:**

- We built the drag-and-drop engine **from scratch**. — Ми написали рушій drag-and-drop з нуля.

## serve
**serve** /sɜːv/ — <code>verb</code> (дієслово) — 1. подавати (їжу) 2. обслуговувати 3. слугувати (чимось)

**Пояснення:** базове значення — «подавати, обслуговувати». Звідси й слово **server**: буквально «той, хто обслуговує» — офіціант або сервер.

**💡 Сервер робить саме це:** the server **serves** requests / static files — сервер обслуговує запити / віддає статичні файли. Також **serve as** sth — слугувати чимось.

**Приклади:**
- This Node.js server **serves** thousands of requests per second. — Цей Node.js-сервер обслуговує тисячі запитів на секунду.
- Dinner is **served**! — Вечерю подано!
- The old tower **serves as** a lighthouse. — Стара вежа слугує маяком.

## settle

- slang: Her demo **slayed** at the meetup. — Її демо розірвало зал на мітапі.

## so
**so** /səʊ/ — 1. <code>adverb</code> (прислівник) 2. <code>conjunction</code> (сполучник) — 1. так, настільки 2. тому, отже

**Пояснення:** як прислівник підсилює прикметник чи прислівник («настільки»); як сполучник вводить наслідок («тому»).

**💡 so vs such (граматична пара):** **so + прикметник/прислівник** (без іменника): so fast, so quickly. Якщо далі є **іменник** — потрібне [such](#such): such a fast app. Порівняй: The app is **so fast**. = It is **such a fast app**.

**Приклади:**
- adverb: This library is **so** heavy! — Ця бібліотека така важка!
- conjunction: The test failed, **so** I checked the logs. — Тест упав, тому я перевірив логи.

## spawn
**spawn** /spɔːn/ — <code>verb</code> (дієслово) — 1. з'являтися, «спавнитися» (в іграх) 2. породжувати, запускати (процес)

- You'll **respawn** at the last checkpoint. — Ти відродишся на останньому чекпоінті. _(гра)_
- Node can **spawn** a child process for heavy tasks. — Node може запустити дочірній процес для важких задач.

**Приклади:**
- The troll has enormous **strength** but little intelligence. — У троля величезна сила, але мало розуму. _(фентезі)_
- Fast startup is the app's main **strength**. — Швидкий запуск — головна сильна сторона застосунку.

🔗 **Пов'язане:** strong — сильний (прикметник).

## such
**such** /sʌtʃ/ — <code>determiner</code> (означник) — такий

**Пояснення:** підсилює іменник (із прикметником або без): such a mess — «отакий безлад».

**💡 so vs such (граматична пара):** **such + (a/an) + (прикметник) + іменник**: such **a fast app**, such **nice people** (множина — без артикля). Без іменника — потрібне [so](#so): the app is **so** fast.

## suspend
